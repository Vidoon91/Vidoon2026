# Vidoon 支付系统部署说明

## 上线前要求

- 服务器 PHP 启用 `mysqli`、`openssl`、`curl` 和 `json` 扩展。
- 订阅站点必须使用有效的 HTTPS 证书。
- 支付宝需要开通当面付，并准备 APPID、应用私钥和支付宝公钥。
- 微信支付需要开通 Native 支付，并准备商户号、APPID、商户证书序列号、API v3 密钥、商户私钥和微信支付平台证书。

## 后台配置

1. 登录 `admin/payment_settings.php`。
2. 设置三个订阅套餐的名称、有效天数和价格。
3. 上传支付通道资料，但暂时不要打开支付总开关。
4. 确认页面显示“配置完整”。
5. 打开“预览订阅页”检查套餐显示。
6. 启用一个支付通道及支付总开关。
7. 使用真实注册邮箱进行小额订单测试。

## 回调地址

- 支付宝：`https://license.muyanshidai.com/payment_notify_alipay.php`
- 微信支付：`https://license.muyanshidai.com/payment_notify_wechat.php`

如果服务器实际域名不同，需要同步修改 `runtime_settings.php` 中的 `site.base_url`。

## 官网订阅地址

后台账号管理中的官网链接建议设置为：

`https://license.muyanshidai.com/subscribe.php`

## 人工收款模式

没有微信或支付宝商户号时，可以先在后台“支付配置”中启用人工收款：

1. 开启支付总开关和人工收款开关。
2. 上传微信或支付宝个人收款二维码，填写收款人名称。
3. 用户下单付款后提交付款人、交易单号、付款时间和截图。
4. 管理员在“订单管理”中查看截图并对照真实收款账单。
5. 只有点击“确认开通”后，系统才会更新订阅并发送邮件。

付款截图自动保存到网站目录之外的 `license_private/payment_proofs`，不能通过公开网址直接访问。
人工收款没有平台到账回调，禁止仅凭截图未经账单核实直接确认开通。

## 订单邮件通知

后台“支付配置”可以单独配置订单邮件 SMTP：

- 订单创建后立即通知下单账号邮箱和管理员通知邮箱，不以是否付款为前提。
- 人工付款凭证提交后发送等待审核通知。
- 人工审核驳回后发送驳回原因。
- 自动支付成功或人工确认到账后发送订阅开通结果。
- SMTP 授权码加密保存在数据库中，重新保存时留空会保留原授权码。

QQ邮箱通常使用 `smtp.qq.com`、端口 `465`、`SSL` 和邮箱生成的 SMTP 授权码。
保存配置后使用“发送测试邮件”验证服务器是否可以正常连接发件服务器。

## 安全说明

- 支付密钥和证书经过 AES-256-GCM 加密后保存在 `payment_settings` 表。
- 加密密钥由数据库密码派生。修改数据库密码后，需要重新上传支付密钥和证书。
- 付款成功只以支付平台验签后的服务器回调为准。
- 订单金额、套餐天数和账号到期时间全部由服务器计算。
- 相同订单的重复回调不会重复延长订阅。
